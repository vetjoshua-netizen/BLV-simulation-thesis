# BLV model workflow (v2)

Run scripts from this directory in RStudio. Keep the old `results/factorial_100_runs`
folder: it was generated by the earlier model and cannot be pooled with v2 results.

1. `source("test.model_v2.R")` checks transmission, birth, and vaccine take.
   `source("test.interventions.R")` checks corrective management, vaccination,
   test-and-remove, and their combined execution.
2. `source("burnin_initialization.R")` explores one infected animal introduced
   into an otherwise uninfected herd. It runs 3 herd sizes (100/200/800) x 3
   index ages (calf/heifer/cow) x 2 index states (I_L/I_H) = 18 scenarios,
   initially with 20 independent runs per scenario and a configurable 100-year
   observation limit. This may take many hours. Change `n_runs` or
   `horizon_years` at the top of the script before running if needed.
   To extend only selected scenarios later, set `n_runs=200L` and put their
   IDs from `scenario_grid.csv` in `selected_scenario_ids`. Existing matching
   runs are loaded, while only the additional replicates are simulated.
   Each run is saved immediately under `results/introduction_burnin/scenario_###/`
   so an interrupted batch can resume. Each completed scenario also has an
   aggregate RDS, yearly CSV, summary row, PNG, and PDF. The plots show all
   trajectories, including zero-prevalence runs, and total/I_L/I_H prevalence.
3. Review the curves with the supervisor to choose a common observation
   period and how to describe persistence and conditional late prevalence.
   The script does not declare a convergence year or an endemic equilibrium.
4. `run_factorial_scenarios.R` still implements the previous initialization
   workflow and does not consume the new introduction results. Decide the
   intervention starting state before running or updating that script.

The current factorial uses herd size 100/200/800, management reductions
0/25/50/90/99%, seven test strategies, and vaccination coverage 0/50/100%:
315 scenarios. When a distinct C50 coverage has been estimated, enter it in
`run_factorial_scenarios.R`; the design then has 420 scenarios. Prior output
files are left intact.

`simulation.R` contains the model, `analysis.R` contains shared summaries,
`simulation.run.R` is a manual example. `explore_results.R` and
`recalculate_eradication_time.R` remain for the previous 112-scenario output.
`test.baseline.R` targets the earlier model and is retained for reference.
Use `test.model_v2.R` and `test.interventions.R` for the current logic.

Model assumptions needing review: the supplied beta coefficients for
unvaccinated susceptible cattle are per day and are multiplied by 365 to match
the simulation's yearly clock. They are used in a herd-wide frequency-dependent
FOI with denominator N. Coverage
controls uptake. Vaccine take is all-or-nothing with efficacy 0.70: a
successful dose moves a susceptible animal to lifelong, fully protected R;
a failed dose leaves S with the original infection risk and no repeat dose.
The supplied Sv and LIv coefficients are recorded in the parameter list but
are inactive under this vaccine rule.
A 5% annual BLV-specific
death rate for infected cows is currently retained from the parameter table,
but should not be cited as the lifetime 2-5% lymphoma risk.
Female calf entry is represented directly as 0.38 live female calves per
cow-year. The model does not separately simulate sex or immediate neonatal
loss, so neither 0.50 nor 0.93 is applied again.
New infections, including perinatal infection, are assigned I_L with
probability 0.70 and I_H with probability 0.30, independently of the infecting
animal's state. The introduction pilot overrides this only for the single
index animal: each scenario starts with exactly one I_L or one I_H and no other
infected cattle. Only infected cows
have additional BLV-specific
removal, at 0.05 per year; calf and heifer BLV-specific rates are zero.
